  1. Open the downloaded file in Apple Shortcuts and choose Add Shortcut. The notification trigger and Title, Subtitle, Body, and Date are already wired.
  2. Open the imported shortcut, expand its notification trigger, and turn on Automation. Imported automations start off. Review any system permission prompts and Allow Running When Locked where offered.
  3. Receive a notification with a text preview from that source, then check NotGone’s Capture health. A real receipt verifies the connection; adding the shortcut or running a synthetic storage check does not.

Each installer is for one named app. Keep its source trigger unchanged. For another app, install its separate shortcut and select that source in NotGone; multiple sources require Pro.

Only delivered notification text can be saved. Earlier messages, attachments, and hidden previews cannot be retrieved. These installers contain workflow logic only; captured notification content stays in NotGone on the device.
