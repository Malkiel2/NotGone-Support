Set up capture in NotGone

The current test build includes its capture shortcut. Start in NotGone → Settings → Install capture shortcut. A website download is no longer needed.

  1. Choose your source in NotGone → Settings → Sources, and enable capture.
  2. Tap Install capture shortcut, choose Shortcuts, then Add Shortcut.
  3. Open NotGone-Universal, choose the source apps in its notification trigger, and turn on Automation. The notification fields are already connected.
  4. Keep earlier NotGone automations off to avoid duplicate captures.
  5. Receive a real notification, then check NotGone’s Inbox and Capture health.

The local installer and all six field mappings have been checked on an iPhone running iOS 27.2. Real notification delivery and locked-device checks are still being verified. A storage check alone does not verify capture.

Capture filtering, archive storage and search run locally. Receiving new messages may require a connection in the source app. First-time system import with all networking disabled has not yet been verified.

No system-wide notification wildcard or Select All option has been verified. Choose the apps offered by the system.
